# Smart Campus Operations Hub

![Smart Campus Operations Hub Banner](https://raw.githubusercontent.com/SasikaShehan/smart-campus-operations-hub/main/assets/banner.png)

A modern platform for managing campus operations, including authentication, notifications, bookings, and more.

## Features
- User Authentication & Authorization (with 2FA)
- Real-time Notifications
- Facility & Booking Management
- Role-based Access

## Getting Started

1. Clone the repository
2. See backend and frontend folders for setup instructions
